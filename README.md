A clean, modern, and tactile web calculator application built with vanilla JavaScript, HTML5, and CSS3. Features a dark neumorphic/glassmorphism design, responsive button feedback, and instant arithmetic evaluation.

---

## ✨ Features

- **Core Operations:** Addition, subtraction, multiplication, and division.
- **Immediate Feedback:** Clear all (`AC`) and backspace/delete (`DEL`) single-character controls.
- **Responsive Layout:** Works smoothly on desktop, tablets, and smartphones.
- **Keyboard & Click Support:** Tactile button states with hover and active animations.
- **Zero Dependencies:** Pure vanilla JavaScript with no external libraries.

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Ryzen2310/Web-Calculator.git

# Navigate into directory
cd Web-Calculator

# Open in browser
start index.html
```
